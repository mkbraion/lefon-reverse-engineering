# Suporte — Lefon Engenharia Reversa

Obrigado por usar a Lefon Engenharia Reversa.

## Onde pedir ajuda

- **Bug reproduzível:** abra uma issue usando o template de bug.
- **Sugestão ou funcionalidade:** use o template de feature request.
- **Dúvida de documentação:** abra uma issue de documentação.
- **Questão de segurança:** siga as instruções de `SECURITY.md`; não publique vulnerabilidades sensíveis em issues públicas.

## Antes de abrir uma issue

Inclua sistema operacional, versão do Node.js, comando executado, logs relevantes e passos mínimos para reproduzir. Remova tokens, chaves de API, credenciais e dados privados.

## Escopo de uso

A Lefon deve ser utilizada em software próprio, ambientes autorizados, pesquisa legítima, interoperabilidade, auditoria e educação. O usuário é responsável por possuir autorização para analisar o alvo.
