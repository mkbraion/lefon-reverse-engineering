# Contribuindo com a Lefon Engenharia Reversa

Obrigado pelo interesse em contribuir com a versão brasileira.

1. Crie uma branch para sua alteração.
2. Faça alterações pequenas e testáveis.
3. Não remova avisos de licença ou atribuições de terceiros.
4. Rode os testes relevantes antes do commit.
5. Abra um Pull Request explicando o problema, a solução e como validar.

Para detalhes técnicos adicionais, consulte `CONTRIBUTING.md`.
